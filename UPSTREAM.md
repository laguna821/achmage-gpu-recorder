# Provenance

GPU Screen Recorder by dec05eba is the Linux project that inspired this application.
Official source: https://repo.dec05eba.com/gpu-screen-recorder
Reference checkout: d2cff49dd5146941fde801186924b2a0e06da363 (2026-10-14).
The local reference checkout is in upstream/gpu-screen-recorder, excluded from this repository.

The Windows and macOS backends here are new platform-specific implementations. They are not official ports endorsed by the upstream author, and do not claim Linux feature parity.
